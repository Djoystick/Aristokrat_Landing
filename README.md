# 🎭 Театральная студия «Артистократ» (Курск)

> Современный высокотехнологичный одностраничный сайт студии театрального искусства со своей сценой в Курске. Разработан в эстетике сценического нуара и золотых софитов с применением дизайн-паттернов [vibeprompts.dev](https://vibeprompts.dev).

---

## 🌟 Ключевые особенности и технологии

- 🔦 **Интерактивный Canvas-софит (`spotlight.js`)**: кинематографичный луч прожектора, следующий за курсором мыши, с парящими сценическими частицами света и пыли.
- 🎟️ **Интерактивный «Театральный Билет»**: стилизованный перфорированный билет со штрихкодом и валидацией номера для онлайн-записи на бесплатное пробное занятие.
- 🖼️ **Visual Showcase Фотогалерея**: подлинные сценические снимки высокого разрешения со спектаклей и репетиций, категориальные фильтры и полноэкранный просмотрщик (Lightbox).
- 🎭 **Репертуар и Афиша**: карточки ключевых постановок («Очень простая история», «У ковчега в восемь», «Алиса в стране чудес», «Мед, шарики и большие приключения»).
- 📱 **Mobile First & Ultra-fast**: идеальная адаптивность для любых экранов, плавающий навигационный бар (Quick Navigation Dock).
- 🚀 **Готовность к мгновенному деплою**: оптимизированная конфигурация для Vercel и GitHub Pages.

## 🛠️ Запуск локально

Для локального запуска не требуется сторонних зависимостей (достаточно установленного Node.js):

```bash
# Запуск локального сервера
npm run dev

# Проверка откроется по адресу:
# http://localhost:3000
```

Для проверки целостности всех файлов и ресурсов:
```bash
npm test
```

## 🚀 Деплой на Vercel и GitHub

1. Инициализируйте git-репозиторий и отправьте код на GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release v1.0.0"
   git remote add origin https://github.com/<username>/artistokrat-theater.git
   git push -u origin main
   ```
2. Импортируйте репозиторий в [Vercel](https://vercel.com).
3. Проект автоматически определит статическую сборку и файл `vercel.json`.
