## 2. Архитектура и Дизайн-система (vibeprompts.dev)

### Цветовая палитра (Stage Noir & Gold Glow)
| Цвет / Роль | HEX / RGBA | Назначение |
|---|---|---|
| Deep Stage Noir | `#09090b` / `#0d0e12` | Основной фон зрительного зала и сценического пространства |
| Stage Glass Surface | `rgba(24, 24, 27, 0.7)` | Карточки, bento-блоки, навигационная панель с эффектом `backdrop-blur-xl` |
| Spotlight Gold | `#f59e0b` / `#fbbf24` | Теплый сценический свет софитов, акцентные кнопки, маркеры |
| Amber Glow | `rgba(245, 158, 11, 0.15)` | Рассеянное свечение прожектора, свечение карточек при наведении |
| Velvet Wine | `#7f1d1d` / `#991b1b` | Микро-акценты благородного театрального занавеса |
| Crisp White | `#fafafa` | Заголовки, акцентные тексты высокой контрастности |
| Muted Silver | `#a1a1aa` / `#71717a` | Второстепенные описания, технические подписи |

### Шрифтовая система
- **Акцидентные заголовки**: `Cormorant Garamond` / `Playfair Display` — сценический драматизм, благородство аристократического театра.
- **Интерфейс и контент**: `Inter` — геометрическая чистота, идеальная читаемость на экранах любой плотности.

## 3. Архитектура экранов и Повествовательная Схема (Narrative Flow)

Последовательность блоков спроектирована по логике зрительского погружения:
1. **Hero Screen (`#hero`)**: Первое впечатление, динамический луч софита, фирменный логотип, ключевые метрики доверия (4 дня аншлагов, своя сцена, 100% на сцене).
2. **О студии (`#about`)**: Симметричный Bento Grid (2 ряда по 3 колонки: 2+1 и 1+2): Сценическая база, свобода от зажимов, голос и ораторское слово, репертуарный театр.
3. **Мастер курса и Режиссер (`#director`)**: Представление художественного руководителя Евгения Игоревича Сетькова, его сценическая философия и авторский подход.
4. **Направления обучения (`#courses`)**: 
   - Симметричная сетка 2x2 для 4 возрастных групп (5–7 лет, 8–12 лет, 13–17 лет, 18+).
   - Полноразмерный горизонтальный мастер-баннер под сеткой: «Индивидуальные занятия & Подготовка в театральные ВУЗы».
5. **Репертуар и Афиша (`#plays`)**: Сетка 2x2 кинотеатральных постеров постановок с бронированием мест в зале.
6. **Фотогалерея Visual Showcase (`#gallery`)**: Настоящая Pinterest/vibeprompts-стиль CSS Columns Masonry без пустых зон с категориальной фильтрацией и полноэкранным Lightbox.
7. **Интерактивный Театральный Билет (`#ticket`)**: Модуль прямой активации пригласительного билета прямо на странице с анимацией печати и номером билета, плюс резервное модальное окно.
8. **Частые вопросы (`#faq`)**: Аккордеон с ответами на ключевые вопросы новичков.
9. **Контакты и Локация (`#contacts`)**: Адрес (ул. 50 лет Октября, 143А), телефоны, VK-сообщество и стилизованная ночная карта Яндекс.
